# OpenCMS domain vocabulary

## Project

A user's isolated workspace. A project owns its content, schema, and development and production environments.

## Content type

A named kind of content, such as a Page or Article. It defines the fields and blocks an entry may contain.

## Entry

A piece of content belonging to a content type and project. An entry has identity fields such as a title and slug, plus structured content.

## Page

The built-in content type used for routable website content. A Page is an Entry whose content is composed of blocks.

## Block

A typed, ordered unit inside an entry's content, such as a heading, text section, quote, or feature list.

## Schema

The contract describing a project's content types, fields, and allowed blocks.

## Environment

A project state in which content is managed. Development is editable; production is the deployed state.

## Deployment

The promotion of a project's development content into production.
